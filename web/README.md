# 🌐 web/ — the website

A statically exported Next.js site (App Router, TypeScript, Tailwind CSS v4, shadcn/ui). It reads `../generated/catalog.json` at build time and is deployed by Vercel with this folder as the root directory. No Python runs here.

```text
web/
├── src/app/          routes (thin: they only compose components)
├── src/components/   presentation (ui/ holds the shadcn primitives)
├── src/lib/          logic and data access, unit-tested
└── public/           static files (public/assets/ is copied at build time and gitignored)
```

| Command | Purpose |
|---------|---------|
| `npm install` | install dependencies (Node 24+) |
| `npm run dev` | local preview at http://localhost:3000 |
| `npm run build` | static export to `out/` |
| `npm run lint` · `npm run typecheck` | quality checks (also run in CI) |

Edit this folder when changing the site's design or behavior. Specs: [04 — UI/UX](../docs/specs/04-ui-ux-spec.md).

`AGENTS.md` is generated by `next dev` with guidance for AI coding agents and is kept in git on purpose.
